# SJ ACT — Image Assets

Place your image assets here.  They are declared in pubspec.yaml under:

  flutter:
    assets:
      - assets/images/

## Required files (replace placeholders before publishing)

| File | Size | Usage |
|---|---|---|
| `usa_flag.png` | 64×64 | USA Room badge in online challenge |
| `globe.png` | 64×64 | Foreign Room badge in online challenge |
| `act_logo.png` | 256×256 | App logo for splash and about screens |

Until you add real assets, the app uses text-based placeholders for all
of the above so it will still build and run correctly.
